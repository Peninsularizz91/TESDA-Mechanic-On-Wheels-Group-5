# TESDA-Mechanic-On-Wheels-Group-5
TESDA "Mechanic-On-Wheels" Mobile-Responsive SPA Prototype built with Tailwind CSS and Vanilla JavaScript. by Engr. CJ Torres, ECE, ECT

---

## 🛠️ Tech Stack
* **Frontend Structure:** HTML5 / Single-File Architecture (SPA)
* **Styling & UI Design:** Tailwind CSS (via CDN)
* **Interactivity & State Management:** Vanilla JavaScript (ES6+)
* **Graphics & Branding:** Custom SVG mathematical gear topology & tailored brand logo integration (`Asset/Logo.png`)
---

## ✨ Key Features
1. **Role-Based Portals:** Dedicated interfaces and workflows for both **Motorists** (client assistance request) and **Mechanics** (job dispatch & navigation).
2. **Multi-Step Registration Flows:**
   * **Motorist Registration:** Vehicle details, personal info, and secure account setup.
   * **Mechanic Registration:** Comprehensive 2-step verification including personal data, home address, government-issued ID upload, live selfie capture, specializations, certifications/clearances, and service radius.
3. **Interactive Simulation & Dashboards:**
   * Live status tracking and radar animations.
   * Gear pop-up navigation featuring profile editing and transaction history shortcuts.
   * Real-time dispatch acceptance and job completion handlers.
